# Arbor 软件使用演示

本演示使用当前项目桌面版 v0.1.7 的真实界面，配合用户提供的深度学习综述 PDF，实际完成导入、元数据核对、阅读提问、引用核对、高亮、问题贴纸、截图翻译、保存笔记与摘录、Word 导出、研究主题、阅读计划、画布连线与导出、快速捕获待办等操作。

## 建议先打开交互版

双击 **Arbor-使用演示.html**，使用 Edge 或 Chrome 打开。此文件已经包含全部界面素材，无需安装依赖、连接模型服务或提供密钥。

- 点击“播放”开始，空格键暂停或继续。
- 点击底部进度条，或使用章节下拉框跳转。
- 左右方向键切换镜头；可选择播放速度。
- 点击“鼠标自由查看”暂停并进入查看模式：移动鼠标平移关注区域，滚轮缩放；双击恢复 100%。
- 点击“返回自动运镜”后继续播放；“全屏”按钮可放大观看。

## 关于真实性和边界

软件界面采用实际操作时采集的画面，逐步编排后叠加演示鼠标、缩放运镜与字幕；它是演示动画，不是未经剪辑的连续录屏。模型等待过程已压缩。鼠标自由查看是演示播放器的功能。

AI 回答、翻译、阅读计划与文档均来自用户指定服务的实际调用。保留实际输出，并在整理文档时要求根据原文核对和纠正不严谨表述。演示用于介绍软件操作，AI 输出仍应核对论文。

论文为 Jürgen Schmidhuber 的《Deep learning in neural networks: An overview》，Neural Networks 61 (2015), 85–117，DOI：10.1016/j.neunet.2014.09.003。PDF 第 4 页对应期刊第 88 页。演示中保留了软件自动提取 2014、再根据正式卷年校正为 2015 的操作。

全部演示产物保存在项目目录之外。未修改原项目代码与文档，未改动原有文献库。交付文件不包含 API 密钥、独立演示实例的用户数据目录或凭据配置。
